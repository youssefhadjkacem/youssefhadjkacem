## Featured Project — AI Emergency Savior
**AI Emergency Savior: Adaptive Multi-Objective Optimization for Emergency Resource Recommendation**  
*(PCD 2025-2026 — ENSI, supervised by Dr. Rihab Said)*

Led the design and development of an intelligent voice-powered medical recommendation system that instantly analyzes patient symptoms and recommends the **optimal healthcare provider** by simultaneously optimizing multiple conflicting criteria (distance, waiting time, cost, and service quality).

- **Voice-First Interaction** — Real-time speech-to-text with Whisper (fine-tuned on medical vocabulary + multi-accent support) + automatic emergency keyword detection  
- **Symptom-to-Specialty Mapping** — NLP pipeline (Hugging Face Transformers) with symptom extraction, text preprocessing, and weighted scoring against a medical ontology (ICD-10 / SNOMED CT)  
- **Multi-Objective Optimization Core** — Implemented **MOEA/D** (with NSGA-II baseline) to generate the full Pareto front of non-dominated solutions  
- **Smart Provider Ranking** — Dynamic filtering + personalized scoring based on patient age, urgency, preferences, and real-time availability  
- **Computer Vision Module** — OCR (EasyOCR / Tesseract) for medical documents, prescriptions, and IDs  
- **Geolocation & Real-Time Data** — Google Maps API for precise distance & travel-time calculation  
- **Cloud & Continuous Learning** — Full-stack architecture (FastAPI backend + React frontend) with PostgreSQL, Docker, and adaptive retraining
